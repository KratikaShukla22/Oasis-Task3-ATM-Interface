# ATM Interface — Java

A console-based ATM application developed using Java as part of the Oasis Infobyte Java Development Internship.

## Features

- PIN-based authentication
- Check account balance
- Withdraw money with validation
- Deposit money with validation
- Transaction history
- Continuous menu until exit
- Validation for invalid amounts and insufficient balance

## Technologies Used

- Java
- Maven
- IntelliJ IDEA

## Default Credentials

- **PIN:** `1234`
- **Initial Balance:** ₹10,000

*Note: This is a beginner-level educational project. The PIN and balance are stored in memory and are reset when the program restarts.*

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure a compatible JDK is installed.
4. Run `ATM.java`.
5. Enter the PIN `1234` to access the ATM menu.

## Learning Outcomes

This project helped practise Java conditionals, loops, input handling, `ArrayList`, transaction tracking, and basic validation.
